# Definition of Done

A phase is complete only when:
- Its acceptance criteria are met and relevant behavior is implemented (not just scaffolded).
- Relevant tests, typecheck, lint, and build have been run where scripts exist; results are reported accurately.
- No known critical/high-severity defect introduced by the phase remains unresolved.
- Authorization, validation, privacy, and failure states are checked where relevant.
- No dead buttons, fake analytics, fabricated test results, or hidden failing tests.
- Docs/STATE.md is current; roadmap status and ADR are updated only when applicable.
- Manual device-only checks are labeled untested until actually performed.
